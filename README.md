# HexForge

Просмотр, анализ и редактирование бинарных файлов с локальным ИИ.

## Возможности

- Просмотр данных в HEX, текстовом режиме и в виде строк.
- Редактирование байтов с отменой и повтором изменений.
- Декодирование данных в UTF-8, UTF-16 LE/BE, ASCII, Windows-1251 и KOI8-R.
- Анализ выделенных байтов с помощью локальной ИИ-модели.
- Тёмный интерфейс с подсветкой выделения и изменённых данных.

## Установка

1. Скачайте установщик из раздела **Releases**.
2. Выберите папку и следуйте инструкциям.
3. Запустите HexForge после завершения установки.

## Использование

Откройте файл, выделите нужные байты и выберите действие: редактирование, декодирование или ИИ-анализ.

Перед редактированием важных файлов создавайте резервную копию. Ответы ИИ могут содержать ошибки.

## Исходный код

Исходный код не опубликован. Доступны только готовые сборки.
